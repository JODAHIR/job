Cómo usar la pizarra

Tu pizarra se sincroniza con Firebase. Necesitás conexión y autorización del administrador.

Arrastrá cada tarjeta desde su cabecera.
Podés cargar imágenes, PDF, Word, Excel, TXT, CSV o PowerPoint.
Usá el buscador para filtrar por título o contenido.
El botón de papelera envía una tarjeta a la papelera.
Los elementos eliminados pasan a la papelera. El administrador puede restaurarlos.
